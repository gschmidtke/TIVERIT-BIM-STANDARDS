# Migration Workspace

This directory contains non-canonical artifacts used to transform the existing Confluence BST corpus into governed GitHub objects.

Planned contents:

- `mappings/` — Confluence page IDs and legacy IDs to canonical TIVERIT IDs
- `gaps/` — unresolved conflicts, missing data, and migration questions
- `review/` — curator review records and promotion decisions
- `inventory/` — normalized copies/indexes of the Confluence migration inventory where appropriate

Migration artifacts support traceability but do not become normative authority merely by existing in this directory.
