# Public Inbox

`inbox/` is the only public contribution surface for TIVERIT BIM Standards.

Content placed here is a proposal, submission, observation, review, evidence item, or candidate change. It is **not canonical authority**.

## Contribution lifecycle

```text
public proposal
    -> inbox/
    -> curator review
    -> classification / normalization
    -> schema / reference / provenance validation
    -> governed promotion when justified
    -> canonical repository content
```

## Rules

- External pull requests may modify only `inbox/**`.
- Do not treat Inbox content as an active BIM requirement.
- Do not overwrite canonical IDs from the Inbox.
- Preserve contributor and source provenance.
- Curator review is required before promotion.
- Canonical repository areas are edited only in curator sessions.
- A merged Inbox submission remains non-authoritative until separately promoted through governance.

See `CONTRIBUTING.md` for the public submission process and `CURATION.md` for promotion rules.
