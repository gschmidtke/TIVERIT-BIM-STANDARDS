# Public Inbox

`inbox/` is the public contribution surface for TIVERIT BIM Standards.

Content placed here is a proposal, submission, observation, or candidate change. It is **not canonical authority**.

## Contribution lifecycle

```text
public proposal
    -> inbox/
    -> curator review
    -> schema/reference/provenance validation
    -> governed promotion
    -> canonical repository content
```

## Rules

- Do not treat inbox content as an active BIM requirement.
- Do not overwrite canonical IDs from the inbox.
- Preserve contributor/source provenance.
- Curator review is required before promotion.
- Once governed operation begins, canonical areas are edited only in curator sessions.
